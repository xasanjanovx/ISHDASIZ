# Обновление платформы — 20 октября 2026

## База данных: установка и проверенное состояние

Проверка рабочей базы 20 октября подтвердила обе части обновления: `ishdasiz_catalog_version()` возвращает `2`, новая функция пакетной очереди установлена. Повторное применение на этом проекте не требуется. Ниже сохранён порядок установки для других копий базы.

1. Откройте проект ISHDASIZ в Supabase → **SQL Editor → New query**.
2. Скопируйте **весь** файл `supabase/releases/2026-10-20-platform.sql`.
3. Выполните запрос от роли `postgres`. Скрипт рассчитан на существующую октябрьскую схему проекта. Он добавляет индексы и обновляет функции очереди; объявления и аккаунты не удаляются.
4. Если появилась ошибка, сохраните её текст и остановитесь. Обходить её отключением ограничений доступа не нужно.
5. После успешного выполнения проверьте:

```sql
select public.ishdasiz_catalog_version(); -- ожидается 2
```

Приложение проверяет версию с кэшем 30 секунд. В обновлённой базе отдельный индексированный запрос получает только ID удалённых вакансий с кэшем 60 секунд; итоговый поиск по региону и тексту проверяет актуальную доступность. Это исключает тяжёлое вычисление формата из JSON внутри регионального OR. До установки работает совместимый прежний путь. Скрипт включает две миграции: `20261020090000_catalog_filter_indexes.sql` и `20261020091000_osonish_queue_performance.sql`; отдельно повторять их не требуется.

После обновления базы запустите новый импорт в админке. Проверьте завершение цикла, количество обработанных карточек и отсутствие `last_error`. Ошибочный прежний цикл не следует считать успешно законченным. Очередь продолжает работу с подтверждённых контрольных точек; временная ошибка источника не означает, что вакансию нужно удалить.

## Восстановление доступа

- Сайт: вход → роль → свой телефон → **Забыли пароль?** → новый SMS → новый пароль. Автозаполнение полного пятизначного кода поддерживается. Старые использованные или просроченные коды не принимаются.
- Админка: `/admin/login` → **Забыли пароль?** → свой email → ссылка из письма → новый пароль длиной от 12 символов. Пароли и коды в переписку не отправляйте.
- Ссылка восстановления проверяется Supabase Auth. В настройках Supabase **Authentication → URL Configuration** добавьте `https://ishdasiz.uz/admin/reset-password` в Redirect URLs; Site URL должен быть `https://ishdasiz.uz`. Если разрешён только Site URL, приложение также обрабатывает пришедшую на главную ссылку восстановления.

Фактическую доставку SMS и письма подтверждает владелец аккаунта: при проверках разработки сообщения не отправлялись, пароль принудительно не менялся.

## Что уже проверено в данных

Официальный справочник OsonIsh содержит 10 основных направлений, все они уже присутствуют в ISHDASIZ. Новые направления добавляются при синхронизации, существующие идентификаторы и локальные названия сохраняются. Не следует использовать ID группы профессии как ID основного направления: это разные справочники.

20 октября справочник профессий пересчитан по 49 099 импортированным объявлениям, включая историю: 2 828 профессий. Это число объявлений, а не число рабочих мест внутри объявлений; `vacancy_count` хранится отдельно.

Импорт читает публичный постраничный каталог OsonIsh, затем отдельные карточки, приводит поля к общей схеме и сохраняет состояние источника. Он сверяет существующие импортированные объявления, сохраняет архив и ручные изменения. Полный цикл не имеет фиксированной длительности: она зависит от числа карточек, ответа источника и базы; точное время следует оценивать по завершённому циклу после установки SQL.

## Telegram и оплата

На сайте размещение вакансий бесплатное. Продвижение в основном канале `@ishdasiz` оформляется через `@ishdasiz_admin`. Выбор тарифа и копирование заявки не списывают деньги и не публикуют объявление автоматически. Региональные каналы и основной канал — разные назначения.

Команды бота: `/app` — сайт как Web App, `/tariffs` (также `/tarif`, `/tariflar`) — тарифы. Публичная аудитория считывается из Telegram и базы с кэшем; двойные роли не удваивают число людей в тарифном сообщении. Цифры не записаны в текст вручную.

После публикации работодатель видит до восьми рекомендаций из открытых активных резюме по профессиональным условиям. Если соответствий нет, показывается честное пустое состояние и ссылка на каталог. Заказ продвижения не зависит от наличия кандидатов.
